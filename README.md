# Events Microservice - English Imperatives & Should Examples

## 📝 5 Sentences Using Imperatives (Giving Instructions)

1. **Configure the R2DBC connection URL in the application.yml file before starting the microservice.**

2. **Install Java 17 and Maven on your system to compile and run the Events Microservice.**

3. **Use the Docker Compose file to deploy both the application and PostgreSQL database together.**

4. **Execute the Maven clean install command to build the project and generate the JAR file.**

5. **Send a POST request to /api/v1/events endpoint to create a new academic event in the system.**
